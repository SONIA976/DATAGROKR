## Project Description

The Student Grade Calculator is a command-line Python application that accepts student marks for Python, SQL, and Git.

The program calculates the total marks, average marks, grade, and pass/fail status.

The results are also stored in a CSV file for future reference.

## Features

- Accepts student name and subject marks
- Validates marks between 0 and 100
- Handles invalid input using exception handling
- Calculates total marks
- Calculates average marks
- Assigns grades based on average marks
- Displays PASS or FAIL status
- Stores student results in a CSV file
